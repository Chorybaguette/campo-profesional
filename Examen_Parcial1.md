## Tecnologías actuales relacionadas
### 1.- [MySQL](https://www.mysql.com/)
MySQL es un sistema que gestiona bases de datos con codigo abierto. Este utiliza el lenguaje SQL para crear, modificar, analizar y administrar información a traves de tablas.
MySQL es una tecnología muy usada en aplicaciones web, en sistemas empresariales y en otras plataformas que necesitan almacenar información de manera estructurada.
#### Uso principal
- Almacenar información de manera estructurada.
- Crear y también administrar tablas.
- Realizar consultas por SQL.
- Gestionar información de aplicaciones web.
- Administrar datos.
- Crear sistemas que requieren consultas y transacciones.

- Almacenar grandes cantidades de información.

### 3.-[MongoDB](https://www.mongodb.com/es/docs/manual)
MongoDB es una tipo base de datos NoSQL orientada a documentos. En vez de organizar la informaciónpor tablas. almacena datosen documentos con una estructura parecida a JSON.
Su esquema flexible nos permite adaptar los datos a las necesidades de distintas aplicaciones, ademas de que facilita el desarrollo de sistemas modernos.
#### Uso principal
- Almacenar documentos y datos.
- Desarrollar aplicaciones web y móviles.
- Trabajar con grandes cantidades de datos.
- Crear aplicaciones que necesitan esquemas flexibles.
- Utilizar bases de datos NoSQL.
Construir sistemas escalables.

### 4.-[Microsoft SQL Server](https://www.microsoft.com/en-us/sql-server)
Microsoft SQL Server es un tipo de sistema de gestión de bases de datos relacionales desarrollado por Microsoft. Las aplicaciones pueden relacionarse a sus bases de datos a la vez que comunicarse mediante Transact-SQL.
Actualmente SQL Server también cuenta con herramientas para aplicaciones empresariales, disponibilidad alta, seguridad, análisis de datos y servicios en la nube.
#### Uso principal
- Administrar Bases de datos empresariales.
- Almacenar y consultar información.
- Crear sistemas de datos.
- Gestionar grandes cantidades de información.
- Desarrollar aplicaciones empresariales.
- Implementar soluciones de alta disponibilidad y recuperación.

### 5.-[Redis](https://redis.io/docs/latest/)
Redis es una de las tecnologías de almacenamiento de datos en memoria que tiene la capacidad de utilizarse como base de datos, caché, motor de streaming y sistemas de mensajería. Está diseñada para ofrecer respuestas rápidas y trabajar con aplicaiones que necesitan procesar toda la información a tiempo real.
#### Uso principal
- Crear sistemas de caché.
- Procesar información eficazmente.
- Manejar datos a tiempo real.
- Crear sistemas de mensajería.
- Procesar eventos.
- Mejorar el rendimiento de aplicaciones.
- Trabajar con las aplicaciones que requieren de baja latencia.
